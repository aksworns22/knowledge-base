
# [[LLM 라우터]]가 뭐예요?

- 통일된 프로토콜 / 인터페이스
	- 대표 프로토콜 : OpenAI(Chat completion API, Responses API), Anthropic (Messages API)
- 모델 라우팅
- 접근 통제
- 비용 추적 및 비용 최적화

## OpenAI 프로토콜

- 많은 프로젝트들이 차용
- 쉬운 마이그레이션 가능

## Anthropic 프로토콜

- 코드 관련은 Anthropic 프로토콜이 표준
- Claude 관련 에코시스템을 지원한다면 피할 수 없다.

# 왜 직접 만들었어요?

API 키 관리 + 자체 서빙 모델 제공을 하고 싶었다.
서비스 레벨에서 에러를 인프라팀에서 능동적으로 대응하고 싶었다

## 내부적인 요구사항

- 사용성 : 벤더 별 모델 특수 기능 사용 가능
- 비용 추적
- 프로토콜: 프로토콜 지원의 완결성

## 달성하고자 하는 목표

- API 키 관리 단순화
- 전사가 통합된 프로토콜로 빠르게 [[LLM]] 관련 기능 개발
- AI 비용 추적

- OpenAI의 extra_body

[[vLLM]]은 대규모 언어 모델(LLM)을 빠르고 효율적으로 실행하고 API로 제공하기 위한 오픈소스 추론·서빙 엔진이다.
- 높은 GPU 메모리 효율
- 높은 처리량
- 간편한 API (OpenAI 호환)
- 다양한 최적화
